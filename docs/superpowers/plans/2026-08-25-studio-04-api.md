# implr Studio — Plan 4: HTTP & WebSocket API

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Expose the registry, pipeline config, and orchestrator over a localhost-only HTTP API with a WebSocket that streams run events live and replays history from a cursor on reconnect.

**Architecture:** FastAPI application factory taking an injected `AppContext` (workspace, registry, contracts, store, orchestrator), so tests construct an app wired to `FakeExecutor` and a temp workspace with no globals. Routes are thin: validate, delegate to Plan 1–3 code, serialize. The WebSocket polls the store's monotonic `events.seq` cursor — deliberately simple, because SQLite is local and a poll loop has no cross-process coordination to get wrong.

**Tech Stack:** Python 3.11+, FastAPI, Uvicorn, `httpx` + `fastapi.testclient` for tests, pytest, pytest-asyncio.

**Spec:** `docs/superpowers/specs/2026-08-25-implr-studio-design.md`

## Global Constraints

- The server binds `127.0.0.1` **only**. Binding another interface is not a configuration option, and no CLI flag may offer one.
- The workspace path is fixed at startup. **No route may accept a filesystem path from the client** — that would let a request redirect agent execution at another directory.
- `args` are validated against the registry `args_allowed` whitelist before reaching the orchestrator, and passed as an argument vector — never interpolated into a shell string.
- No authentication is implemented, because the service must never be reachable by anyone but the local operator. This is a deployment constraint, not a gap to fill later.
- Save-time validation returns HTTP `422` with a list of findings — never a bare 400 with a string.

```python
"""Pure dict conversions for API responses. No FastAPI imports belong here."""
from .pipeline import Finding, Pipeline, pipeline_to_dict
from .registry import PHASES, Registry, Step


def step_to_dict(step: Step) -> dict:
    return {
        "id": step.id,
        "label": step.label,
        "phase": step.phase,
        "skill": step.skill,
        "args_allowed": list(step.args_allowed),
        "args_default": list(step.args_default),
        "interactive": step.interactive,
        "produces": list(step.produces),
        "description": step.description,
        "available": step.available,
    }


def registry_to_dict(reg: Registry) -> dict:
    return {
        "steps": [step_to_dict(s) for s in reg.steps.values()],
        "phases": list(PHASES),
    }


def finding_to_dict(f: Finding) -> dict:
    return {"code": f.code, "message": f.message, "node_id": f.node_id}


def contracts_to_dict(contracts) -> dict:
    """Expose the artefact state machines so the frontend never copies them.

    Statuses live in status-vocabulary.json. A hardcoded TypeScript copy would be
    a second source of truth and would drift the moment a state is added.
    """
    out: dict = {}
    for artefact, spec in contracts.artefact_types.items():
        fields = set(spec.get("required", [])) | set(spec.get("optional", []))
        for rule in spec.get("conditional_required", []):
            fields.update(rule.get("require", []))
        out[artefact] = {
            "states": list(contracts.machines[spec["status_machine"]]["states"]),
            "fields": sorted(fields),
        }
    return out


def _node_to_dict(row: dict) -> dict:
    return {
        "node_id": row.get("node_id"),
        "status": row.get("status"),
        "summary": row.get("summary"),
        "error": row.get("error"),
        "manual_approved": bool(row.get("manual_approved", 0)),
        "started_at": row.get("started_at"),
        "finished_at": row.get("finished_at"),
    }


def run_summary(run_row: dict, node_rows: dict) -> dict:
    return {
        "id": run_row["id"],
        "status": run_row["status"],
        "created_at": run_row["created_at"],
        "updated_at": run_row["updated_at"],
        "node_count": len(node_rows),
    }


def run_detail(run_row: dict, node_rows: dict, p: Pipeline) -> dict:
    return {
        "id": run_row["id"],
        "status": run_row["status"],
        "created_at": run_row["created_at"],
        "updated_at": run_row["updated_at"],
        "nodes": {k: _node_to_dict(v) for k, v in node_rows.items()},
        "pipeline": pipeline_to_dict(p),
    }


def event_to_dict(row: dict) -> dict:
    return {
        "seq": row["seq"],
        "node_id": row["node_id"],
        "kind": row["kind"],
        "payload": row["payload"],
        "created_at": row["created_at"],
    }
```

```python
"""The wired-up dependency bundle, built once at startup and injected everywhere.

Nothing in the API layer reaches for a global. Tests build a context pointed at a
temp workspace and a FakeExecutor, and get a fully functional app.
"""
from dataclasses import dataclass
from pathlib import Path

from .implr_bridge import load_contracts, repo_root, resolve_schema_dir
from .orchestrator import Orchestrator
from .registry import load_registry
from .store import Store

PIPELINE_RELPATH = Path("docs") / "implr" / "config" / "pipeline.yaml"
DB_RELPATH = Path("docs") / "implr" / ".studio" / "runs.db"


@dataclass
class AppContext:
    workspace: Path
    registry: object
    contracts: object
    store: Store
    orchestrator: Orchestrator
    pipeline_path: Path


def build_context(workspace: Path, executor, db_path: Path | None = None) -> AppContext:
    workspace = Path(workspace).resolve()
    schema_dir = resolve_schema_dir(workspace)
    contracts = load_contracts(str(schema_dir))

    # Step definitions and skills live in the implr repo, not the target project.
    reg = load_registry(schema_dir, repo_root() / "skills")

    store = Store(db_path or workspace / DB_RELPATH)
    orchestrator = Orchestrator(workspace, reg, contracts, executor, store)
    orchestrator.recover()

    return AppContext(
        workspace=workspace,
        registry=reg,
        contracts=contracts,
        store=store,
        orchestrator=orchestrator,
        pipeline_path=workspace / PIPELINE_RELPATH,
    )
```

```python
"""FastAPI routes. Thin: validate, delegate to the orchestrator, serialize.

Security: the workspace is fixed in AppContext at startup. No route accepts a
filesystem path from the client, so no request can redirect execution elsewhere.
"""
from fastapi import Body, FastAPI, HTTPException, WebSocket, WebSocketDisconnect

from . import serialize
from .context import AppContext
from .pipeline import (
    Pipeline,
    PipelineError,
    pipeline_from_dict,
    pipeline_to_dict,
    save_pipeline,
    validate_pipeline,
)
from .gates import validate_gate

EMPTY_PIPELINE = {"version": 1, "nodes": [], "edges": []}


def _validate(p: Pipeline, ctx: AppContext) -> list[dict]:
    findings = [serialize.finding_to_dict(f) for f in validate_pipeline(p, ctx.registry)]
    for edge in p.edges:
        findings.extend(
            serialize.finding_to_dict(f) for f in validate_gate(edge.gate, ctx.contracts)
        )
    return findings


def create_app(context: AppContext) -> FastAPI:
    app = FastAPI(title="implr Studio", version="0.1.0")
    app.state.ctx = context

    @app.get("/api/registry")
    def get_registry() -> dict:
        # Contracts ride along with the registry so the frontend makes one call
        # and never hardcodes implr's status vocabulary.
        return {
            **serialize.registry_to_dict(context.registry),
            "contracts": serialize.contracts_to_dict(context.contracts),
        }

    @app.get("/api/pipeline")
    def get_pipeline() -> dict:
        if not context.pipeline_path.is_file():
            return {"pipeline": EMPTY_PIPELINE, "exists": False}
        import yaml
        data = yaml.safe_load(context.pipeline_path.read_text(encoding="utf-8")) or {}
        return {"pipeline": data, "exists": True}

    @app.put("/api/pipeline")
    def put_pipeline(body: dict = Body(...)) -> dict:
        try:
            p = pipeline_from_dict(body)
        except PipelineError as e:
            raise HTTPException(422, detail={"findings": [
                {"code": "parse-error", "message": str(e), "node_id": None}
            ]})

        findings = _validate(p, context)
        if findings:
            raise HTTPException(422, detail={"findings": findings})

        save_pipeline(context.pipeline_path, p)
        return {"pipeline": pipeline_to_dict(p), "exists": True}

    _register_run_routes(app, context)
    return app
```

Note: FastAPI wraps `HTTPException.detail` in a `{"detail": ...}` envelope. To make the tests above read `r.json()["findings"]` directly, add this exception handler inside `create_app`, before `return app`:

```python
    from fastapi.responses import JSONResponse
    from fastapi.exceptions import HTTPException as _HTTPException

    @app.exception_handler(_HTTPException)
    async def _unwrap_findings(request, exc: _HTTPException):
        if isinstance(exc.detail, dict) and "findings" in exc.detail:
            return JSONResponse(status_code=exc.status_code, content=exc.detail)
        return JSONResponse(status_code=exc.status_code, content={"detail": exc.detail})
```

```python
def _register_run_routes(app: FastAPI, context: AppContext) -> None:
    from .orchestrator import OperatorActionError, UnavailableStepError
    from .pipeline import load_pipeline

    orch = context.orchestrator
    store = context.store

    def _detail_or_404(run_id: str) -> dict:
        run = store.get_run(run_id)
        if run is None:
            raise HTTPException(404, detail="unknown run: %s" % run_id)
        return run

    @app.post("/api/runs")
    async def start_run() -> dict:
        if not context.pipeline_path.is_file():
            raise HTTPException(409, detail="no pipeline saved for this workspace")
        p = load_pipeline(context.pipeline_path)
        try:
            run_id = await orch.start_run(p)
        except UnavailableStepError as e:
            raise HTTPException(422, detail=str(e))
        await orch.wait_quiescent(run_id)
        return {"run_id": run_id}

    @app.get("/api/runs")
    def list_runs() -> dict:
        return {"runs": [
            serialize.run_summary(r, store.get_nodes(r["id"])) for r in store.list_runs()
        ]}

    @app.get("/api/runs/{run_id}")
    def get_run(run_id: str) -> dict:
        run = _detail_or_404(run_id)
        return serialize.run_detail(run, store.get_nodes(run_id), run["pipeline"])

    @app.post("/api/runs/{run_id}/answer")
    async def answer(run_id: str, body: dict = Body(...)) -> dict:
        _detail_or_404(run_id)
        try:
            await orch.answer(run_id, body["question_id"], body["text"])
        except KeyError as e:
            raise HTTPException(404, detail=str(e))
        await orch.wait_quiescent(run_id)
        return {"ok": True}

    @app.post("/api/runs/{run_id}/approve")
    async def approve(run_id: str, body: dict = Body(...)) -> dict:
        _detail_or_404(run_id)
        try:
            await orch.approve(run_id, body["node_id"])
        except OperatorActionError as e:
            raise HTTPException(409, detail=str(e))
        except KeyError as e:
            raise HTTPException(404, detail=str(e))
        await orch.wait_quiescent(run_id)
        return {"ok": True}

    @app.post("/api/runs/{run_id}/nodes/{node_id}/retry")
    async def retry(run_id: str, node_id: str) -> dict:
        _detail_or_404(run_id)
        try:
            await orch.retry(run_id, node_id)
        except OperatorActionError as e:
            raise HTTPException(409, detail=str(e))
        except KeyError as e:
            raise HTTPException(404, detail=str(e))
        await orch.wait_quiescent(run_id)
        return {"ok": True}

    @app.post("/api/runs/{run_id}/nodes/{node_id}/skip")
    async def skip(run_id: str, node_id: str) -> dict:
        _detail_or_404(run_id)
        try:
            await orch.skip(run_id, node_id)
        except OperatorActionError as e:
            raise HTTPException(409, detail=str(e))
        except KeyError as e:
            raise HTTPException(404, detail=str(e))
        await orch.wait_quiescent(run_id)
        return {"ok": True}

    @app.post("/api/runs/{run_id}/cancel")
    async def cancel(run_id: str) -> dict:
        _detail_or_404(run_id)
        await orch.cancel(run_id)
        return {"ok": True}
```

Design note: every mutating route awaits `wait_quiescent` before returning, so the HTTP response reflects a settled run. With the concurrency cap at 1 this keeps the API honest and the tests deterministic. When the cap is raised in a later phase, these routes should return immediately and let the WebSocket carry progress — revisit then, not now.

```python
    @app.websocket("/api/runs/{run_id}/stream")
    async def stream(websocket: WebSocket, run_id: str, cursor: int = 0) -> None:
        import asyncio

        await websocket.accept()
        run = store.get_run(run_id)
        if run is None:
            await websocket.send_json({"type": "error", "message": "unknown run: %s" % run_id})
            await websocket.close()
            return

        last_status = None
        try:
            while True:
                events = store.events_since(run_id, cursor)
                if events:
                    cursor = events[-1]["seq"]
                    await websocket.send_json({
                        "type": "events",
                        "events": [serialize.event_to_dict(e) for e in events],
                        "cursor": cursor,
                    })

                current = store.get_run(run_id)
                status = current["status"] if current else None
                if status != last_status:
                    last_status = status
                    await websocket.send_json({"type": "run-status", "status": status})

                # Drain the backlog before closing, so nothing is lost on a fast run.
                if status in rs_module.RUN_TERMINAL and not store.events_since(run_id, cursor):
                    await websocket.close()
                    return

                await asyncio.sleep(0.25)
        except WebSocketDisconnect:
            return
```

Add this module-level function:

```python
_NOT_BUILT = """<!doctype html>
<meta charset="utf-8">
<title>implr Studio</title>
<h1>implr Studio backend is running</h1>
<p>The API is live at <code>/api/registry</code>, but the user interface has not been built.</p>
<h2>Development</h2>
<pre>cd studio/frontend
npm install
npm run dev</pre>
<p>Then open the address Vite prints (it proxies <code>/api</code> here).</p>
<h2>Single-process use</h2>
<pre>cd studio/frontend
npm install
npm run build</pre>
<p>Then restart <code>implr-studio</code> and reload this page.</p>
"""


def mount_frontend(app: FastAPI, dist_dir) -> bool:
    """Serve the built SPA at / when it exists. Returns whether it was mounted.

    A missing dist/ is normal during development, when Vite serves the UI and
    proxies /api here - so it is reported, not raised.
    """
    dist_dir = Path(dist_dir)
    if not (dist_dir / "index.html").is_file():
        return False
    # Mounted last so it cannot shadow /api; html=True serves index.html for
    # unknown paths, which is what a single-page app needs.
    app.mount("/", StaticFiles(directory=str(dist_dir), html=True), name="frontend")
    return True
```

Add the root fallback inside `create_app`, immediately before `_register_run_routes`:

```python
    @app.get("/", response_class=HTMLResponse, include_in_schema=False)
    def index() -> str:
        return _NOT_BUILT
```

`mount_frontend` is called by `server.py`, after the app is fully constructed, so the
catch-all mount is always registered after every `/api` route. A route registered before a
mount wins, which is what `test_api_routes_still_win_over_the_spa_mount` pins down.

# implr Studio

A visual builder and orchestrator for implr pipelines. Compose an SDLC process by
dragging steps onto a canvas, save it as `docs/implr/config/pipeline.yaml` in your

## How it fits together

| Piece | Where |
|---|---|
| Available steps | `scaffold/schemas/step-registry.json` |
| Your saved pipeline | `<workspace>/docs/implr/config/pipeline.yaml` |
| Run history | `<workspace>/docs/implr/.studio/runs.db` |
| Gate vocabulary | `scaffold/schemas/status-vocabulary.json` (single source of truth) |

Adding a step to the palette means adding an entry to `step-registry.json` — no code
change. A step whose skill does not exist yet appears greyed out, so you can draw a

## Security

This service runs an agent that writes files and executes shell commands in your
repository. It therefore:

- binds `127.0.0.1` only, with no flag to change that;
- fixes the workspace at startup, so no request can redirect it elsewhere;
- runs with `acceptEdits` plus an explicit tool allowlist, never `bypassPermissions`;
- ships no authentication, because it must never be reachable by anyone else.

Do not put it behind a tunnel, a reverse proxy, or a port-forward.
